# Examples / Framework Fixtures

These directories are **validation fixtures**, not promoted end-user plugins.

```text
ui-smoke-test      signed browser-UI sandbox/navigation/bridge fixture
upload-smoke-test  basic package upload/lifecycle fixture
```

They are retained because they provide small reproducible tests for the plugin framework without overloading the real RX Monitor plugin.

For normal plugin development see [`docs/DEVELOPMENT.md`](../docs/DEVELOPMENT.md).
