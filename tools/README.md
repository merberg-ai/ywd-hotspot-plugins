# Tools

The active development tree intentionally contains **one current RX Monitor tool directory**:

```text
tools/rx-monitor/
```

Normal users should run the top-level wrapper instead of invoking internal tooling directly:

```bash
./BUILD-RX-MONITOR.sh
```

Older Phase 3C–3J proof directories were removed from the active tree after the streamed Alpha19 path was selected. They remain available in Git history and retained checkpoint refs; see [`docs/history/RX-MONITOR-DEVELOPMENT.md`](../docs/history/RX-MONITOR-DEVELOPMENT.md).
